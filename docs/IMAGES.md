# Codex App 图片输入

BPS 通道支持 HTTPS 图片链接、PNG / JPEG / GIF / WebP 的 base64 data URL，以及 BPS 附件 ID。Codex App 拖入或粘贴的内嵌图片会自动上传为附件，再传给所选模型。`auto`、`low`、`high` 和 `original` 清晰度参数原样保留，不自动降低清晰度或切换账号、模型、通道。

会话续接会回放历史图片。客户端保留每一处图片及顺序；重复的内嵌图片在单次请求中只解码一次，同账号、同会话的成功附件上传缓存 30 分钟。切换账号后重新上传，不跨账号复用附件。工具返回的截图保持内嵌格式。

桥接层先验证全部图片再上传，最多 4 路并行上传，保持原来的图片顺序。上传失败或请求取消后不发送不完整图片历史。桥接层设置以下本地容量边界：

- 整段请求最多 1500 张图片，包含历史消息、工具截图、HTTPS 链接和附件引用。
- 单张内嵌图片解码后最多 20 MiB；全部内嵌图片按出现次数累计最多 32 MiB。
- HTTP 请求体最多 64 MiB，包含 JSON、base64 图片及文本历史。

这些是本地资源保护限制，不代表 BPS 上游保证接收相同容量。超限提示会说明限制；可压缩图片或压缩会话历史。客户端不会静默删除历史图片，也不会把图片降为文字描述。

协议回归测试使用合成图片和模拟上游，覆盖附件字节、清晰度、超过 20 张的历史回放、去重、账号隔离和失败前置校验：

```sh
go test ./internal/basispoints ./internal/server
```
